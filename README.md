# 空の薬便ルート（sorabin-route）

洪水で道路が使えないとき、薬をドローンで避難所へ運ぶための「飛ぶ高さ」と「道のり」を、国土交通省 PLATEAU の3D都市モデルで決めるWebアプリです。

- 建物モデル（LOD1）から、経路上で一番高い建物を調べ、余裕を足した飛行高度を決めます。
- 洪水浸水想定区域モデルから、浸水想定区域の上を飛ぶ長さを出し、車が使えない区間を示します。
- 地上150m（航空法で許可なしに飛べる上限）を超えないかを確かめます。

対象：仙台市（太白区・若林区・青葉区）。データは PLATEAU 2024 年度の 3D Tiles（PLATEAU配信サービス）。背景は地理院タイル。

## 動かし方
`index.html` をブラウザで開くだけです（CesiumJS を CDN から読み込みます）。

公開版：https://vpgkotaro-jpg.github.io/sorabin-route/

## 注意
- 地点の座標は地図上の概略位置です（デモ用）。
- 地面の高さは経路上の測定値から推定しています。実運用では地形モデルと合わせて使います。
